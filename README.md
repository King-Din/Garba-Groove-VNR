# Garba Groove

Mobile-first, single-scroll Garba/Dandiya event landing experience for Street Cause.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Important placeholders

The event date, time and venue name are intentionally placeholders because they were not supplied. Update `EVENT` in `src/main.jsx`.

The countdown currently uses a sample target date (`2026-10-31T18:00:00+05:30`) and must be changed to the confirmed event date/time.

Real previous-event photographs and verified charity/social-impact content should replace the visual placeholders before launch.
